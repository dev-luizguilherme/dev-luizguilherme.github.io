# Site Portfólio - Luiz Guilherme

## Sobre

Um Site One-Page feito com o objetivo de mostrar Hard Skills, Soft Skills e principais projetos.

## Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript

## Funcionalidades e boas práticas
Mobile First: pensado primeiro para telas pequenas e ampliado para telas maiores.

Design Responsivo: adaptável a diferentes tamanhos de tela.

HTML Semântico: uso de tags que descrevem o significado do conteúdo, ótimo para acessibilidade e SEO.

## Workflow
Planejamento: os dados foram reunidos em um prompt mestre, em planning/prompts/gerar-site-inicial/ (com os anexos usados).

Geração/Modificações com IA: a criação e modificação do design e do código foi gerada por IA generativa de texto.

Versionamento: o projeto usa Git, com commits em português seguindo o padrão tipo: descrição (docs:, feat:, fix:), e o repositório fica no GitHub.
Deploy: o site é publicado no GitHub Pages, a partir da branch main.
